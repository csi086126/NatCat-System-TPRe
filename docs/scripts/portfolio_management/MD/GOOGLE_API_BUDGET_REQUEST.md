## 成本优化措施

我们已采取以下措施降低API使用成本：

1. **地址缓存机制**
   - 相同地址只调用一次API
   - 预计缓存命中率60%+
   - 节省成本约40%

2. **双API策略**
   - Google Maps API（主要，香港地区）
   - 高德地图API（备用，大陆及澳门地区）
   - 预计分流30%请求至高德

3. **请求限速**
   - 限制10次/秒，避免无效请求
   - 防止意外循环导致费用暴增

4. **数据预处理**
   - 清洗重复地址
   - 过滤无效地址
   - 减少不必要的API调用
