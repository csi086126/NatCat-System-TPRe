# 理赔数据字段保留说明

## ✅ 所有Excel字段都会被保留

脚本使用以下逻辑遍历并保留所有原始字段：

```python
# 第84-96行
for col in df.columns:  # 遍历Excel的所有列
    value = row.get(col)
    # 保存到record字典中
    record[col] = value  # 保留原始字段名和值
```

## 🌐 简繁体字段支持

脚本支持以下地址字段名（简体+繁体）：

| 简体 | 繁体 |
|------|------|
| 出险地址 | 出險地址 |
| 保险处所 | 保險處所 |
| 理赔地址 | 理賠地址 |
| 出险地点 | 出險地點 |
| 地址 | 地址 |

**优先级**：按列表顺序查找，找到第一个非空字段即使用。
