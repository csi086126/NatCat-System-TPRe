# 港澳台风暨复合洪水巨灾模型 — 易损性曲线库 建库任务书

> 交付对象：香港 / 澳门 两所合作高校（土木 / 结构 / 水利 / 防灾工程方向）
> 模型定位：港澳复合洪水（+ 可选风灾）巨灾模型，基于 OASIS LMF 框架
> 核心原则：**按"建筑类别"建曲线，而非逐栋建模**。两校必须使用**同一套分类体系**。

---

## 0. 一句话说明任务边界（务必先读）

- 你们要交付的是 **"建筑类别 → 灾害强度 → 损坏率" 的曲线**，类别总数控制在 **30–80 类**。
- 你们 **不需要** 对全城几十万栋楼逐栋编码 —— 那是"暴露数据库（exposure）"的工作，由 GIS + 政府数据团队完成（见另一份任务书）。
- 一条"1980 年前砖混低层住宅"曲线，将自动服务全城同类的所有楼宇。

---

## 1. 第一步：统一分类体系 —— 直接用 OED 现成字段（不另造 GEM）

### 1.1 骨架标准
**直接采用 OED 现有的标准字段作为分类语言**（`OccupancyCode` / `ConstructionCode` 等），不另造一套分类。好处：暴露库与易损性库天然用同一套码对齐、无需额外映射、对外通用。
> GEM Building Taxonomy / GED4ALL 仅作**可选参考**，用于细化港澳本地特殊类别时对照，不作为主线。
> **港澳两校必须采用同一套 OED 字段组合定义**，否则两地曲线无法合并、无法跨区比较。

### 1.2 关键认知：OccupancyCode + ConstructionCode **两个码不足以区分洪水易损性**
两栋同样 `OccupancyCode` + `ConstructionCode` 的楼，若一栋有地库、首层贴地、老旧，另一栋无地库、首层抬高、新建，**水浸损坏率差数倍**。决定洪水损坏率的维度**不在这两个码里**，而在 OED 的其他专门字段。因此每条曲线必须由**一组 OED 字段的组合**来定义。

### 1.3 定义每条曲线的 OED 字段组合键（已核实的精确字段名）

| 维度 | OED 字段（精确） | 取值/分档示例 | 为什么对洪水关键 |
|---|---|---|---|
| 用途 | `OccupancyCode` | 1050住宅 / 1100商业 / 1150工业 … | 内部财产价值密度差异大 |
| 结构 | `ConstructionCode` | 5000钢混 / … | 抗水流冲击能力不同 |
| 年代 | `YearBuilt`（分区间） | <1980 / 1980–2005 / >2005 | 新建筑常含防洪设计 |
| 层数 | `NumberOfStoreys`（分区间） | 低层1–3 / 多层4–7 / 高层8+ | 决定可被淹楼层占比 |
| **有无地库** | `Basement` + `BasementLevelCount` | 有/无；地库层数0–5 | 港澳地库、地铁、地下商场是水浸重灾区，必须单列 |
| **首层抬高** | `FirstFloorHeight`(+`FirstFloorHeightUnit`) | 0 / 0.3 / 0.6 / 1.0m … | 直接决定进水阈值，洪水第一关键字段 |
| 防洪设施（可选） | `FloodDefenseHeight`(+单位) | 有挡水板高度 / 无 | 改变进水阈值 |
| 防洪标准（可选） | `CustomFloodSOP` | 重现期 0–10000 年 | 区域防洪能力 |

> 其他可用的 OED 洪水修正字段（如需更细）：`GroundElevation`/`Datum`/`BaseFloodElevation`（高程，注意 BaseFloodElevation 是水面高程**不是水深**）、`FloorsOccupied`、`FoundationType`、`SoftStory`、`ServiceEquipmentProtection`、`FloodDebrisResilience`、`FEMACompliance`。
> OED 还有 `BuildingFloodVuln` / `ContentsFloodVuln` / `BIFloodVuln` / `VulnerabilitySetID` 等**位置级洪水易损性修正码**，可在暴露层对个别标的微调，不替代曲线库本身。

### 1.3 港澳本地特征必须细化的类别（不能用国际通用类糊弄）
- 香港：唐楼、村屋（新界）、填海区高层、劏房密集楼、地铁/地下商场
- 澳门：内港老旧低层、新口岸高层、地库停车场、世遗历史建筑

### 1.4 交付物 A
> **《港澳统一建筑分类定义文档》**：列出最终 30–80 个类别，每类的 **OED 字段组合取值**（见 1.3）+ 文字定义 + 典型代表建筑照片/案例。

## 2. 第二步：为每个类别 × 每种灾因 建立 depth-damage 曲线

### 2.1 灾因清单（强度量纲）

| 灾因代码 | 名称 | 强度量纲 | 备注 |
|---|---|---|---|
| WSS | 风暴潮淹没 | 淹没水深 (m) | 需含咸水/波浪冲击修正 |
| ORF | 河流 / 上游洪水 | 淹没水深 (m) | 可选流速修正 |
| OSF | 暴雨内涝 / 地表积水 | 淹没水深 (m) | 台风雨与非台风雨共用曲线 |
| WTC（可选） | 台风强风 | 风速 (m/s) | 仅在做风灾时交付 |

> 注：台风暴雨 与 非台风暴雨 **共用同一组 OSF 曲线**（同为雨水内涝，物理损坏机理相同）；两者的区别在事件集层面（event 来源），不在易损性层面。

### 2.2 每条曲线要给的内容
对每个 (类别, 灾因)，给出一组离散点：

| 字段 | 说明 |
|---|---|
| 淹没水深 (m) | 例如 0.0, 0.3, 0.5, 1.0, 1.5, 2.0, 3.0, >3.0 |
| 平均损坏率 (MDR) | 0–1，该水深下的建筑+财产平均损坏比例 |
| 损坏率不确定性 | 标准差 或 分位数(P10/P50/P90)，**必须给**，用于 OASIS 概率式易损性 |
| 适用 TIV 构成 | 该损坏率针对 Building / Contents / BI 哪部分 |

### 2.3 数据来源优先级
1. **历史灾损反演（最可信）**：天鸽(Hato 2017)、山竹(Mangkhut 2018)、2008/2023 香港暴雨的实际理赔/查勘/政府灾损统计 → 拟合曲线。
2. **工程数值/试验**：构件淹水破坏分析、有限元。
3. **专家判断 + 国际曲线校准**：数据不足时，以 **HAZUS Flood depth-damage** / **JRC 全球洪水曲线** 为基线，用本地少量样本调整，并标注"借用+校准"。

### 2.4 交付物 B
> **《港澳洪水易损性曲线参数表》**（每类每灾因一组：水深点 + MDR + 不确定性 + 数据来源标注 + 校准方法说明）。

## 3. 与 OASIS / OED 的衔接（你团队做，非高校）

高校交付的连续曲线，由本团队转换为 OASIS 概率式易损性：

```
vulnerability.csv:
vulnerability_id, peril_id, intensity_bin_id, damage_bin_id, probability
```

- 每个 `(peril, intensity_bin)` 对应一个 **损坏率的概率分布**（在 damage_bin 上离散），这就是 2.2 里"不确定性"的用途。
- 同时建立类别 → OED 字段映射（见下）。

### 3.1 组合键 → vulnerability_id 映射（必须双校一致）

每条曲线由以下 OED 字段组合唯一确定一个 `vulnerability_id`：

| OED 字段 | 角色 | 示例值 |
|---|---|---|
| `OccupancyCode` | 用途 | 1050 / 1100 / 1150 … |
| `ConstructionCode` | 结构 | 5000 … |
| `YearBuilt`（分区间） | 年代 | <1980 / 1980–2005 / >2005 |
| `NumberOfStoreys`（分区间） | 层数 | 低/多/高层 |
| `Basement` / `BasementLevelCount` | 地库 | 有/无, 0–5 |
| `FirstFloorHeight`（分档） | 首层抬高 | 0 / 0.3 / 0.6 / 1.0m |
| `FloodDefenseHeight`（可选, 分档） | 防洪设施 | 有/无 |
| → `vulnerability_id` | 曲线库主键 | 映射到 vulnerability.csv |

> ⚠️ OED 的 `OccupancyCode`/`ConstructionCode` 是开放的粗框架，**单用这两个不足以区分洪水易损性**。必须叠加上表的高程/地库/年代字段组合。**指令应为"按 OED 字段组合定义曲线"，而非"只按 OccupancyCode 分类"。**

---

## 4. 验收标准（Checklist）

- [ ] 双校使用**同一套** OED 字段组合键，类别数 30–80
- [ ] 组合键已含洪水关键字段（`FirstFloorHeight`/`Basement`/`YearBuilt` 等），非仅 Occupancy+Construction
- [ ] 港澳本地特殊建筑（地库/唐楼/村屋/内港老楼/世遗）已单独成类
- [ ] 每类 × 每洪水灾因（WSS/ORF/OSF）均有 depth-damage 曲线
- [ ] 每条曲线含**均值 + 不确定性**（非单一确定值）
- [ ] 历史灾损（天鸽/山竹/暴雨）已用于至少主要类别的校准
- [ ] 借用国际曲线的类别已明确标注来源与校准方法
- [ ] 提供 OED 字段组合键 → `vulnerability_id` 映射表
