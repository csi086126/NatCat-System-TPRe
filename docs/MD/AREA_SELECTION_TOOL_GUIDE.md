# Area Selection Tool - 用户指南

## 功能概述

在Portfolio Map View中添加了区域选择工具，允许用户通过绘制几何图形（圆形、矩形、多边形）来圈选地图区域，并自动统计该区域内的保单数据。

## 功能特性

### 1. 绘图工具
- **圆形 (Circle)**: 点击圆形图标，在地图上点击并拖动绘制圆形区域
- **矩形 (Rectangle)**: 点击矩形图标，在地图上点击并拖动绘制矩形区域
- **多边形 (Polygon)**: 点击多边形图标，在地图上依次点击多个点形成多边形，双击完成绘制

### 2. 编辑功能
- **编辑形状**: 点击编辑按钮，可以拖动调整已绘制图形的大小和位置
- **删除形状**: 点击删除按钮，可以删除已绘制的图形
- **清除选择**: 使用统计面板中的"Clear Selection"按钮一键清除

### 3. 自动统计分析

当您绘制完成一个区域后，系统会自动计算并显示以下统计数据：

#### 基础统计
- **Policies**: 选定区域内的保单数量
- **Exposure**: 选定区域内的总保额
- **Average**: 平均每份保单的保额
- **Range**: 保额的最小值和最大值范围

#### 分组统计
- **By District**: 按区域（18个香港行政区）分组统计
  - 显示每个区域的保单数量和总保额
  - 按保额降序排列

- **By Occupancy**: 按物业用途分组统计
  - 显示前5个占用类型
  - 包含保单数量和总保额

#### 高风险保单
- **Top 5 by Exposure**: 显示区域内保额最高的5份保单
  - 保单排名
  - 保额金额
  - 具体地址
  - 所属区域和用途

## 使用场景

### 1. 区域风险评估
通过圈选特定区域（如商业中心、工业区），快速评估该区域的累积风险敞口。

### 2. 业务分布分析
使用多边形工具圈选不规则区域，分析业务在地理上的分布特征。

### 3. 集中度检查
通过圆形工具以某个高风险点为中心，检查周边一定半径内的业务集中度。

### 4. 灾害影响评估
当发生自然灾害事件时，使用绘图工具圈选受影响区域，快速统计潜在损失。

## 技术实现

### Point-in-Polygon 算法
系统使用射线投射（Ray Casting）算法进行精确的点在多边形内判断：
- 对于圆形：计算点到圆心的距离是否小于半径
- 对于矩形/多边形：使用ray casting算法判断点是否在多边形内部

### 实时计算
- 所有统计数据都是基于全量数据实时计算
- 支持编辑图形后自动重新计算统计数据
- 无需等待，即时响应

### 性能优化
- 使用Leaflet Draw库提供流畅的绘图体验
- 统计计算在客户端执行，无需服务器往返
- 支持处理数万条保单记录的区域统计

## 操作提示

1. **绘制前建议**: 先通过搜索功能或图层控制熟悉目标区域的位置
2. **精确绘制**: 使用多边形工具可以沿着特定边界（如行政区边界）精确绘制
3. **编辑调整**: 绘制完成后可随时进入编辑模式调整范围
4. **单次选择**: 系统一次只保留一个选区，新绘制会自动清除之前的选区
5. **统计面板**: 统计面板会随着图形的编辑实时更新数据
