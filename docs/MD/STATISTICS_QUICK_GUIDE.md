# 统计分析功能快速使用指南

## 3步开始使用

### 1. 选择数据源和视图
```
1) 点击 "🏢 Direct Insurance" (左侧栏)
2) 确保选中 "🗺️ Map" 视图
```

### 2. 选择统计维度
在左侧 **"📊 Statistics Analysis"** 区域，点击任一维度：

| 按钮 | 功能 | 数据展示 |
|------|------|---------|
| **📍 District** | 按地区分析 | 18个香港地区的保额分布（柱状图） |
| **📅 Year** | 按年度趋势 | 2021-2024年度趋势（折线图） |
| **🏢 Occupancy** | 按经营性质 | 6种业务类型占比（饼图） |
| **🏗️ Construction** | 按建筑等级 | 4种建筑等级分布（饼图） |

### 3. 查看统计结果
- 地图右下角自动弹出统计面板
- 显示汇总数据 + 图表 + 详细信息
- 可最小化（▼）或关闭（✕）面板

## 功能说明

### 统计面板功能

**📊 汇总卡片**（顶部3个）：
- Total Policies - 保单总数
- Total Exposure - 总保额
- Avg Exposure - 平均保额

**📈 可视化图表**（中间）：
- 自动根据维度选择合适的图表类型
- 鼠标悬停可查看详细数值
- 自动格式化货币（B/M/K）

**ℹ️ 元数据**（底部）：
- Data Source: postgresql（实时数据）或 mock（示例数据）
- Timestamp: 数据获取时间

**控制按钮**：
- **▼ 最小化**: 折叠面板，只显示标题栏
- **✕ 关闭**: 完全关闭面板，返回纯地图视图

## 示例使用场景

### 场景1: 查看地区风险分布
```
目标：了解哪些地区的保额最高

步骤：
1. 点击 📍 District 按钮
2. 查看柱状图，发现"油尖旺"保额最高（HKD 12.3B）
3. 在地图上查找该地区的保单分布
4. 结合地图和统计数据做出风险评估
```

### 场景2: 分析年度增长趋势
```
目标：查看保单数量和保额的年度变化

步骤：
1. 点击 📅 Year 按钮
2. 查看双折线图：
   - 蓝色线：总保额趋势（左Y轴）
   - 绿色线：保单数量趋势（右Y轴）
3. 发现2024年保单数量增长但平均保额下降
4. 提示风险集中度可能降低
```

### 场景3: 分析业务结构
```
目标：了解不同业务类型的占比

步骤：
1. 点击 🏢 Occupancy 按钮
2. 查看饼图显示：
   - 商业: 35.4% (HKD 45.2B)
   - 办公室: 30.4% (HKD 38.9B)
   - 住宅: 33.1% (HKD 42.3B)
   - ...
3. 结合地图查看不同业务类型的地理分布
```

### 场景4: 筛选特定年份数据
```
目标：只查看2023年的地区分布

步骤：
1. 在左侧找到年份选择器
2. 点击 "2023" 按钮
3. 点击 📍 District 按钮
4. 统计面板自动刷新，显示2023年数据
5. 标题栏显示 "📍 By District (2023)"
```

## 快捷操作

| 操作 | 效果 |
|------|------|
| 再次点击已选中的维度按钮 | 关闭统计面板 |
| 点击另一个维度按钮 | 切换统计维度，面板自动更新 |
| 点击面板上的 ✕ | 关闭面板，维度按钮取消高亮 |
| 改变年份筛选器 | 统计面板自动刷新数据 |
| 切换到 Analytics 视图 | 统计面板隐藏，显示完整仪表板 |
| 切换到 Reinsurance 数据源 | 统计面板隐藏（不支持再保险数据） |

## 提示与技巧

### 💡 最佳实践

1. **先选择年份，再选择维度**
   - 这样可以避免不必要的数据重新加载

2. **使用最小化功能查看地图**
   - 需要关注地图细节时，点击 ▼ 最小化面板
   - 保持统计维度选中状态，需要时再展开

3. **结合地图和统计数据**
   - 统计数据提供宏观视角
   - 地图提供地理位置细节
   - 两者结合可以发现更多洞察

4. **切换维度快速探索**
   - 依次点击4个维度，快速了解多维度数据分布
   - 发现感兴趣的维度后，可深入到Analytics页面

### ⚠️ 注意事项

1. **数据源限制**
   - 统计面板仅支持 Direct Insurance 数据源
   - Reinsurance 数据源不显示统计选择器

2. **视图模式限制**
   - 统计面板仅在 Map 视图下可用
   - Analytics 视图有独立的完整仪表板

3. **加载时间**
   - 首次加载维度可能需要1-2秒
   - 切换维度时会有短暂加载动画
   - 数据会被缓存，相同查询会更快

4. **数据准确性**
   - 当前使用Mock示例数据
   - 配置数据库后自动切换到实时数据
   - 元数据会显示当前数据源类型

## 常见问题

### Q: 为什么看不到统计选择器？
**A**: 确保同时满足：
- ✅ 数据源 = Direct Insurance
- ✅ 视图模式 = Map

### Q: 点击维度按钮后没有反应？
**A**: 检查：
1. 浏览器控制台是否有错误
2. 网络请求是否成功（F12 → Network）
3. 刷新页面重试

### Q: 统计数据是实时的吗？
**A**:
- 如果元数据显示 "postgresql"：是实时数据
- 如果显示 "mock"：是示例数据，需要配置数据库

### Q: 如何查看更详细的统计数据？
**A**:
1. 方式1: 悬浮面板足够日常快速查看
2. 方式2: 切换到 Analytics 视图查看完整仪表板
   - 包含详细表格
   - 更多图表类型
   - 交叉分析功能

### Q: 可以同时显示多个统计面板吗？
**A**: 当前版本不支持，一次只能显示一个维度。未来版本会考虑支持多面板对比。

### Q: 统计面板可以拖动吗？
**A**: 当前版本固定在右下角。未来版本会添加拖动功能。
