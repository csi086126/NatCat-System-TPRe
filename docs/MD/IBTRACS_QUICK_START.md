# IBTrACS 台风数据快速开始指南

## 🚀 5分钟快速上手

### 第 1 步：启动应用

```bash
cd flood-catastrophe-insurance-system
npm run dev
```

访问：[http://localhost:3000/riskmap](http://localhost:3000/riskmap)

---

### 第 2 步：开启 IBTrACS 图层

1. 在左侧面板滚动到 **"Global Typhoon Datasets (IBTrACS)"**
2. 点击展开面板
3. 勾选两个图层：
   - ☑️ `Global Typhoon Tracks (IBTrACS Lines)` - 台风路径线
   - ☑️ `Global Typhoon Analysis Points (IBTrACS)` - 台风节点

![示例图](https://via.placeholder.com/600x300.png?text=IBTrACS+Layers+Panel)

---

### 第 3 步：查看台风路径

- 地图会显示全球台风路径数据
- 推荐区域：中国东南沿海、日本、菲律宾附近
- 缩放到合适级别（建议 zoom level 5-8）

---

### 第 4 步：点击查询详细信息

1. **点击任意台风节点**（蓝色点）
2. 等待加载（约 0.5-2 秒）
3. **查看弹窗信息**

#### 弹窗会显示：

## 📊 关键数据解读

### 风速等级
- **34 kt** (63 km/h) - 烈风，开始影响区域
- **50 kt** (93 km/h) - 狂风，显著影响
- **64 kt** (119 km/h) - 飓风/台风强度

### 风圈半径
- **NE/SE/SW/NW** - 四个象限方向
- **单位**: nm (海里) ≈ 1.852 km
- **含义**: 各方向达到该风速的最远距离

### 强度分类
| 最大风速 (kt) | 强度分类        |
|--------------|----------------|
| < 34         | 热带低压        |
| 34-63        | 热带风暴        |
| 64-85        | 台风           |
| 85-105       | 强台风         |
| > 105        | 超强台风       |

## 💡 使用技巧

### 1️⃣ 查找特定台风

**方法 A**: 手动缩放
- 切换到目标区域（如中国东南沿海）
- 寻找密集的台风路径
- 点击路径上的节点查看详情

**方法 B**: 使用区域选择器
- 左上角选择 "Hong Kong" 或 "Macau"
- 地图会自动飞到该区域
- 查看该区域附近的台风路径

### 2️⃣ 对比不同台风

1. 点击第一个台风节点，查看信息
2. 关闭弹窗（点击 X 或地图其他位置）
3. 点击另一个台风节点
4. 对比两者的风速、气压、风圈数据

### 3️⃣ 追踪台风移动

1. 同时开启路径线和节点图层
2. 沿着路径线从起点到终点依次点击节点
3. 观察台风强度的变化趋势

## ⚠️ 常见问题

### Q1: 点击后没有弹窗？

**A**: 可能原因：
- ✅ 确认勾选了 **点图层** (`Global Typhoon Analysis Points`)
- ✅ 点击位置要精准对准节点（蓝色点）
- ✅ 等待 2-3 秒加载时间
- ❌ 如果显示"附近没有IBTrACS台风节点"，请点击更靠近路径的位置

### Q2: 弹窗数据不完整？

**A**: 这是正常现象！
- 并非所有节点都有完整的风圈数据
- 早期数据可能缺少部分字段
- 系统会自动隐藏缺失的数据项

### Q3: 地图上看不到路径？

**A**: 检查以下几点：
- ✅ 确认勾选了 **路径图层** (`Global Typhoon Tracks`)
- ✅ 缩放级别合适（建议 zoom 5-8）
- ✅ 切换到西太平洋区域（WP 海域）
- ✅ 检查 GeoServer 服务是否正常运行

## 🎯 推荐学习案例

### 案例 1: 2013年超强台风海燕 (Haiyan)

**特点**:
- 史上最强台风之一
- 最大风速：155 kt (287 km/h)
- 最低气压：895 hPa
- 64 kt 风圈半径超过 60 nm

**位置**: 菲律宾东部海域
**时间**: 2013年11月

**学习要点**:
- 观察超强台风的风圈结构
- 理解不对称风场特征
- 分析强度变化趋势

### 案例 2: 2018年超强台风山竹 (Mangkhut)

**特点**:
- 影响中国南方及港澳地区
- 最大风速：140+ kt
- 风圈覆盖范围广

**位置**: 南海及中国东南沿海
**时间**: 2018年9月

**学习要点**:
- 观察台风登陆前后的强度变化
- 分析陆地摩擦对台风的影响
- 评估不同区域的风险暴露

### 案例 3: 台风密集区域分析

**目标**: 识别台风高频路径

**步骤**:
1. 将地图缩放到西太平洋全景 (zoom level 5)
2. 观察路径线的密集程度
3. 识别高频台风走廊
4. 点击不同路径上的节点，对比强度

**高频区域**:
- 菲律宾以东海域（生成区）
- 台湾海峡及东南沿海（登陆区）
- 日本九州及冲绳（转向区）

## 📈 进阶应用

### 1. **风险区域评估**

**场景**: 为承保地点评估台风风险

**步骤**:
1. 在地图上定位投保标的位置
2. 查看附近的历史台风路径密度
3. 点击靠近的台风节点，查看风圈覆盖范围
4. 评估34 kt、50 kt、64 kt风圈是否覆盖该位置
5. 统计历史台风影响频率

### 2. **损失场景模拟**

**场景**: 模拟类似强度台风的影响

**步骤**:
1. 选择一个历史台风作为参考
2. 查看其风速、气压、风圈数据
3. 将该台风的参数应用到新的路径
4. 评估潜在影响范围和损失

### 3. **趋势分析**

**场景**: 分析台风活动趋势

**步骤**:
1. 选择特定时间段（如近10年）
2. 统计该时段内的台风数量
3. 分析平均强度变化
4. 识别路径偏移趋势
