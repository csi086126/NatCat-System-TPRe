## 🔄 数据流图

### 1. 用户切换地区

```
用户点击 [🇭🇰 香港 ▼]
         ↓
选择 [🏙️ 深圳]
         ↓
RegionSelector.switchRegion('sz')
         ↓
RegionContext 更新状态
    • currentRegion: 'hk' → 'sz'
    • regionConfig: {...深圳配置...}
         ↓
保存到 localStorage
         ↓
触发 'regionChanged' 事件
         ↓
┌────────────────┬────────────────┬────────────────┐
│                │                │                │
↓                ↓                ↓                ↓
Risk Map       Disaster      Asset         City Info
  ↓                ↓                ↓                ↓
地图中心切换    重新加载数据    更新边界验证    刷新显示
  ↓                ↓                ↓                ↓
加载深圳图层    GET /api/v1/sz/  使用深圳边界    显示深圳信息
                  disasters
```

## 📊 地区配置数据结构

```typescript
RegionConfig {
  ├─ code: string                  // 地区代码
  ├─ name: string                  // 地区名称
  ├─ nameEn: string                // 英文名称
  ├─ nameCn: string                // 中文名称
  ├─ icon: string                  // 图标 emoji
  │
  ├─ coordinates {
  │   ├─ center: [lat, lon]        // 地图中心点
  │   └─ bounds {
  │       ├─ north: number         // 北边界
  │       ├─ south: number         // 南边界
  │       ├─ east: number          // 东边界
  │       └─ west: number          // 西边界
  │   }
  │ }
  │
  ├─ services {
  │   └─ geoserver {
  │       ├─ url: string           // GeoServer WMS 地址
  │       └─ workspace: string     // 工作空间名称
  │   }
  │ }
  │
  ├─ hazardTypes: Array<{
  │   ├─ type: string              // 灾害类型
  │   ├─ enabled: boolean          // 是否启用
  │   ├─ layers: string[]          // 图层列表
  │   └─ weight: number            // 风险权重
  │ }>
  │
  └─ status: string                // 状态：active/development
}
```

## 📈 扩展性设计

### 添加新地区只需 3 步

```
1. 添加地区配置
   ↓
   在 RegionContext 中添加：
   {
     code: 'th',
     name: '泰国',
     icon: '🇹🇭',
     coordinates: {...},
     services: {...},
     hazardTypes: [...]
   }

2. 创建 API 路由
   ↓
   创建文件：
   /api/v1/th/disasters/route.ts
   /api/v1/th/assets/route.ts

3. 准备数据
   ↓
   • 创建数据库 natcat_th
   • 上传 GeoServer 图层
   • 导入灾害数据
```
